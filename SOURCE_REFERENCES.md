# Official source references

Accessed 2026-08-24.

- OA-MAE repository: https://github.com/wadouf/ao-mae
- Copernicus Data Space STAC: https://stac.dataspace.copernicus.eu/v1/
- Copernicus API overview: https://documentation.dataspace.copernicus.eu/APIs.html
- Copernicus Sentinel Hub Process API: https://sh.dataspace.copernicus.eu/process/v1
- Copernicus OAuth token endpoint: https://identity.dataspace.copernicus.eu/auth/realms/CDSE/protocol/openid-connect/token
- Copernicus Sentinel-1 documentation: https://documentation.dataspace.copernicus.eu/Data/Sentinel1.html
- Earth Engine Sentinel-2 surface reflectance: https://developers.google.com/earth-engine/datasets/catalog/COPERNICUS_S2_SR_HARMONIZED
- Earth Engine Sentinel-2 cloud probability: https://developers.google.com/earth-engine/datasets/catalog/COPERNICUS_S2_CLOUD_PROBABILITY
- Earth Engine Sentinel-1 GRD: https://developers.google.com/earth-engine/datasets/catalog/COPERNICUS_S1_GRD
- Earth Engine Open Buildings Temporal: https://developers.google.com/earth-engine/datasets/catalog/GOOGLE_Research_open-buildings-temporal_v1
- Earth Engine Open Buildings V3 polygons: https://developers.google.com/earth-engine/datasets/catalog/GOOGLE_Research_open-buildings_v3_polygons
- Earth Engine service-account authentication: https://developers.google.com/earth-engine/guides/service_account
- Earth Engine image export: https://developers.google.com/earth-engine/guides/exporting_images

The current Copernicus STAC endpoint is the `/v1/` endpoint above. Do not use the retired OpenSearch route. Open Buildings Temporal provides annual layers from 2016 through 2023. Do not invent a 2024 annual layer.
